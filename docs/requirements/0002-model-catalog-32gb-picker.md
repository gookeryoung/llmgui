## 口径

- 新增条目仅作**推荐档位**，体积为公开仓库的取整估算（注释已标注）；精确显存以 `llmgui estimate` 读 GGUF metadata 为准。
- 32B Q4_K_M + q8_0 KV @32k 合计约 25.4GB，属「32G 紧张」，默认不承诺满 32k / 多并发。
- 14B Q4_K_M + q8_0 KV @32k 合计约 13.8GB，属「32G 可跑」，作为 5090D 主力大模型。
- 筛选/排序/搜索只影响前端展示，不改清单数据；不新增后端接口。
